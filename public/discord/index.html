    AI Translate

    Discord

    AI Translate runs inside Vencord, a well-known mod for the Discord app. One command downloads Vencord with AI Translate already inside, about a megabyte, and patches Discord. Nothing is built on your computer.

    導入dōnyū

    Install

    The command runs on a computer: open this page there to copy it.

    Windows

    01 / 05
    1. 01

      Open Windows Terminal or PowerShell.

    2. 02

      Paste this command and press Enter.

      irm https://builds.zolatau.com/install.ps1 | iex
    3. 03

      Pick Install or update with the arrow keys and press Enter. When it asks which Discord to patch, pick the one you use.

      The command closes Discord before patching it.

    4. 04

      Start Discord again.

    5. 05

      Open Settings›Vencord›Plugins›AI Translate, choose a provider and paste your key.

    macOS

    01 / 05
    1. 01

      Open Terminal.

    2. 02

      Paste this command and press Enter.

      sh -c "$(curl -fsSL https://builds.zolatau.com/install.sh)"
    3. 03

      Pick Install or update with the arrow keys and press Enter. When it asks which Discord to patch, pick the one you use.

    4. 04

      Quit Discord and start it again.

    5. 05

      Open Settings›Vencord›Plugins›AI Translate, choose a provider and paste your key.

    Linux

    01 / 05
    1. 01

      Open a terminal.

    2. 02

      Paste this command and press Enter.

      sh -c "$(curl -fsSL https://builds.zolatau.com/install.sh)"

      Atomic systems (Bazzite, Silverblue, SteamOS) need Discord installed as a Flatpak. Nothing goes into the system itself: everything stays in your home folder, and the installer opens that folder to the Flatpak for you. A Discord baked into the system image with rpm-ostree cannot be patched, because its folders are read-only.

    3. 03

      Pick Install or update with the arrow keys and press Enter. When it asks which Discord to patch, pick the one you use.

      It may ask for your password, because Discord usually sits where only an administrator can write.

    4. 04

      Quit Discord and start it again.

    5. 05

      Open Settings›Vencord›Plugins›AI Translate, choose a provider and paste your key.

    Browser

    01 / 04
    1. 01

      Install Tampermonkey, or another userscript manager.

    2. 02

      Open the script. Your userscript manager offers to install it, and keeps it up to date from here afterwards.

      Install the userscript

    3. 03

      Open discord.com and reload the page.

      If the Vencord Web extension is installed, switch it off: this script has Vencord inside it, and two of them in one tab do not get along.

    4. 04

      Open Settings›Vencord›Plugins›AI Translate, choose a provider and paste your key.

    Good to know

    Updates

    AI Translate looks for a new version by itself and installs it in the background. Check for updates, at the bottom of its settings, does the same at once.

    Uninstall

    Run the same command and pick Remove. Discord goes back to exactly how it was, and your settings stay in case you install again.

    Your key stays with you

    Requests are made from Discord's background process, so your key never enters the part of Discord that a web page could reach.

    質問shitsumon

    Questions

    Can my Discord account get banned?

    Vencord's own FAQ says that client mods are against Discord's Terms of Service, but there are no known cases of people banned for using them. The patch only swaps Discord's startup file; your account, settings and messages are not touched.

    Where is my API key stored?

    In Vencord's settings on your computer. It is sent only to the provider you chose.

    AI Translate disappeared after Discord updated

    Run the install command again. It repairs the installation without losing your settings.

    Is it free?

    Yes. The plugin is free and open source. Translation goes through your provider's API, and Groq, Gemini and GLM have free tiers.
