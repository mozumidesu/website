    Telegram

    A userscript that brings AI Translate into Telegram Web, Telegram's own web client, in both Web A and Web K. It has the same features, providers and backup providers as the plugin for Discord.

    Install

    web.telegram.org

    01 / 04
    1. 01

      In a desktop browser, install Tampermonkey or another userscript manager.

    2. 02

      Open the script, and your userscript manager offers to install it.

      Install the userscriptSource code

    3. 03

      Open web.telegram.org and reload the page.

    4. 04

      Click the translate button in the chat bar, press All plugin settings, choose a provider and paste your key.

      The first time the script reaches your provider, your userscript manager may ask whether it can. Allow that address.

    更新kōshin

    Good to know

    Your key stays with you

    It is kept in your userscript manager's storage on your computer, and requests go from your browser to the provider you chose. There is no server in between.

    Telegram Desktop and phones

    Telegram Desktop is a native app and cannot be patched, so on a computer AI Translate for Telegram is the userscript in a browser. There is no version for phones yet.

    Updates

    Your userscript manager looks for a new version by itself. Check for updates, at the bottom of the settings, asks at once.

    Uninstall

    Delete the script in your userscript manager. Nothing else was installed, so nothing else needs removing.
