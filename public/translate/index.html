    What it can do

    Only in the chats you choose

    Auto-translation is switched on chat by chat. Right-click the translate button in the chat bar to switch the current chat, left-click it to open the panel.

    AI Translate: on here AI Translate: off here

    Messages you receive

    Right-click any message and translate it into your language.

    AI Explain

    For a message that a translation alone does not make clear: chat shorthand, a regional word, an inside joke. It names the language, spells the abbreviations out and says what was meant.

    ngl this is lowkey fire fr

    AI ExplainEnglish, internet slang. ngl: not gonna lie. lowkey: kind of, quietly. fire: really good. fr: for real. So: honestly, this is really good.

    Keep part of a message as it is

    Put a word or phrase between two backslashes and it goes out exactly as you typed it. Code in backticks is never translated.

    See what you sent

    Your own messages can keep the original underneath, visible only to you. It is off until you switch it on in the settings.

    Install

    AI Translate runs inside Vencord, a well-known mod for the Discord app. One command downloads Vencord with AI Translate already inside, about a megabyte, and patches Discord. Nothing is built on your computer.

    The command runs on a computer: open this page there to copy it.

    1. Open Windows Terminal or PowerShell.

    2. Paste this command and press Enter.

      irm https://builds.zolatau.com/install.ps1 | iex

    3. Pick Install or update with the arrow keys and press Enter. When it asks which Discord to patch, pick the one you use.

      The command closes Discord before patching it.

    4. Start Discord again.

    5. Open Settings›Vencord›Plugins›AI Translate, choose a provider and paste your key.

    Updates

    AI Translate looks for a new version by itself and installs it in the background. Check for updates, at the bottom of its settings, does the same at once.

    Uninstall

    Run the same command and pick Remove. Discord goes back to exactly how it was, and your settings stay in case you install again.

    質問shitsumon

    Questions

    Is it free?

    Yes. The plugin is free and open source. Translation goes through your provider's API, and Groq, Gemini and GLM have free tiers.

    Can my Discord account get banned?

    Vencord's own FAQ says that client mods are against Discord's Terms of Service, but there are no known cases of people banned for using them. The patch only swaps Discord's startup file; your account, settings and messages are not touched.

    Where is my API key stored?

    In Vencord's settings on your computer. It is sent only to the provider you chose.

    AI Translate disappeared after Discord updated

    Run the install command again. It repairs the installation without losing your settings.

    Found a bug or have an idea?

    The envelope at the top of the plugin's settings opens a form for bug reports and requests, screenshots included. You can also write on the support server.
